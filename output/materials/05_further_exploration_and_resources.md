# Further Exploration & Resources

## Summary

We've explored tokenization as the foundational step for LLMs, converting raw text into numerical tokens. We discussed its necessity for vocabulary management and handling out-of-vocabulary words, and the parameters (vocabulary size, context length) that define a tokenizer. We then delved into the power of sub-word tokenization and examined Byte Pair Encoding (BPE) as a concrete algorithm for achieving it.

## Dive Deeper

To continue your learning journey and get hands-on experience, we recommend the following resources:

*   **Tiktokenizer (OpenAI):** A fantastic interactive tool to see how OpenAI's models tokenize various texts.
    *   **Link:** https://tiktokenizer.vercel.app/

*   **Hugging Face Tokenizer Playground:** Explore different tokenizer types and their behaviors with this interactive tool.
    *   **Link:** https://huggingface.co/docs/transformers/tokenizer_summary

*   **Andrej Karpathy -- "Let's Build the GPT Tokenizer" Tutorial:** A comprehensive, two-hour deep dive into the practical implementation of tokenizers, highly recommended for those who want to understand the code behind it.
    *   **Search for:** "Andrej Karpathy Let's Build the GPT Tokenizer" on YouTube.
